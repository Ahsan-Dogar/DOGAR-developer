## ✨ Features

- 🧭 **Active-section navigation** — navbar highlights the section you're viewing via GSAP `ScrollTrigger`
- 🌌 **Cinematic 3D visuals** — immersive Three.js scenes and parallax background text
- 🎬 **Smooth scroll animations** — buttery GSAP timelines with `ScrollTrigger` & `ScrollToPlugin`
- 🤖 **AI Chat assistant** — Gemini-powered chat to engage visitors
- 🧩 **Complete sections** — Navbar, Hero, About, Skills, Projects, Services, Contact & AI Chat
- 💎 **Premium dark aesthetic** — luxury design with parallax number backgrounds
- 📱 **Fully responsive** — mobile, tablet, and desktop

## 🚀 Quick Start

**Prerequisites:** Node.js

```bash
# 1. Clone the repository
git clone https://github.com/Ahsan-Dogar/DOGAR-developer.git

# 2. Install dependencies
cd DOGAR-developer
npm install

# 3. Set your Gemini API key
#    Create a .env.local file and add:
#    GEMINI_API_KEY=your_key_here

# 4. Run the dev server
npm run dev
```

Open **http://localhost:5173** in your browser.
